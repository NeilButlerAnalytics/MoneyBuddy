## Local connector

The connector is in:

```text
C:\MoneyBuddy\connector
```

Files:

- [server.py](./connector/server.py)
- [config.json](./connector/config.json)
- [config.example.json](./connector/config.example.json)
- [requirements.txt](./connector/requirements.txt)
- [README.md](./connector/README.md)

The connector:

- Uses the private key only on the local server.
- Generates Enable Banking JWTs.
- Lists application metadata and ASPSPs.
- Starts Account Information authorisation.
- Receives the callback.
- Retrieves sessions, account details, balances, and transactions.
- Has no payment routes.
- Does not log private keys, tokens, account numbers, or transactions.

### Start the connector

```powershell
Set-Location C:\MoneyBuddy\connector
python -m pip install -r requirements.txt
python .\server.py
```

Health check:

```

```

## Next required action

Use the Enable Banking Control Panel to create a separate **Production**
application and check whether restricted personal use is available.

Suggested values:

```text
Environment: Production
Application name: MoneyBuddy Personal
Description: Personal, non-commercial finance organiser using read-only account information.
Service: Account Information only, if selectable
Redirect URL: http://localhost:8080/enablebanking/callback, if accepted
```

Generate a new Production RSA key. Do not reuse the Sandbox key.

Before linking HSBC:

1. Confirm that `GB` is available.
2. Confirm that HSBC UK is listed.
3. Confirm that an HSBC personal current account can be linked.
4. Review the restricted non-commercial terms.
5. Confirm whether there is no subscription fee or unexpected charge.
6. Confirm the consent and re-authentication requirements.

Do not link the account if the cost or terms are unclear.

## Important security boundaries

- Never store HSBC passwords.
- Never add provider private keys to Android.
- Never add payment initiation.
- Never use direct HSBC website scraping.
- Never expose the local connector to the public internet.
- Do not use real HSBC data until Enable Banking production terms and cost are
  confirmed.
- Do not claim that Stage 3 is complete until a read-only HSBC account
  connection has been tested and the data path has been reviewed.
